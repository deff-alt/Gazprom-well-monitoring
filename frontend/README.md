# Well Monitor — Gazprom-style login frontend

React + Vite frontend with a full-screen industrial PNG background, Gazprom logo at the upper left, “Энергия для будущего” at the upper right, and a centered translucent glass login panel.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The login form continues to use the project's existing authentication API (`src/api.js`). The demo credentials are shown in the UI as reference text and are not a substitute for backend authentication.
