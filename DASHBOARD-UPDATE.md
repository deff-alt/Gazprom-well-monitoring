# Обновление интерфейса дашборда

В этой версии обновлён только визуальный слой фронтенда и компоненты представления дашборда.

## Что изменено

- Верхняя шапка оформлена в стиле утверждённого макета: логотип «Газпром добыча Краснодар», пользователь и выход из системы.
- Навигация получила иконки, активное состояние и полупрозрачный градиент, который плавно растворяется справа и не перекрывает изображение завода.
- Добавлено фоновое изображение для шапки `frontend/public/images/dashboard-header-background.webp`.
- Карточки KPI приведены к макету: всего скважин, в работе, в ремонте, активные алерты. Значения берутся из API, демонстрационные значения не подставляются.
- Блок карты и карточка ожидания выбора выровнены по размерам и оформлены в едином стеклянном стиле.
- Для карточки ожидания выбора добавлено изображение `frontend/public/images/well-selection-placeholder.webp`.
- Диаграммы по промыслам и статусам приведены к единому оформлению.
- Сохранены обновлённое окно авторизации, маршруты, авторизация, JWT, API-вызовы и серверная бизнес-логика.

## Запуск

Из каталога `frontend`:

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
```

Backend и сервисы в этой версии не изменялись.
